## 4. Observation Schema Details

### Controlled Domains (22 total)

**Core Self-Report**: mood, stress, sleep, functioning, safety, social_support, wellbeing  
**Protective Factors**: family_support, therapist_engagement, access_to_services, stable_housing  
**Events/Context**: threat_event, hearing, investigation_delay, compensation_delay, relocation_stress, rehabilitation_issue, protection_event, recent_episode  
**Text-Engine Aligned**: fear, distress, urgency, negative_affect, threat_context

### Validation Rules

- Domain must be in controlled vocabulary → invalid domains silently dropped
- Evidence is mandatory → observations without evidence are dropped
- Confidence clamped to [0.0, 1.0]
- Semantic values checked against per-domain allowed lists where applicable
