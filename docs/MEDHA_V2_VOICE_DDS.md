# MEDHA V2 STEP 7 — VOICE DDS SPECIALIST REPORT

## 1. Executive Summary

This report documents the implementation, training, evaluation, and boundary validation of the **Voice DDS Specialist** for MEDHA V2.

The Voice DDS Specialist predicts current-timepoint psychological distress (**DDS**) exclusively from acoustic and prosodic indicators generated by audio recordings.

### Key Accomplishments:
- **Pre-trained Voice Engine Preserved**: The acoustic models (`engine/voice_engine/models/voice_distress_model.joblib`, `acoustic_indicator_model.joblib`) and feature extractors remain 100% intact.
- **Accurate Missing-Voice Handling**: Missing voice check-ins (63.35% of workbook rows) are preserved as `NaN` and flagged with `Voice_Available = 0`. In strict compliance with domain specifications, missing voice was **not** converted into "zero distress".
- **Leakage-Safe Feature Selection**: Uses strictly approved voice-derived features from Step 4. All target lags, future targets, structured variables, and text variables are strictly rejected.
- **Authoritative Split**: Trained strictly on available voice observations from the 700 training victims, evaluated out-of-sample on the 150 held-out test victims (1,692 available voice rows).
- **Strong Predictive Signal (Canonical Ridge Model)**:
  - **Test $R^2$**: **0.6529** (vs. naïve baseline $R^2 = -0.0039$)
  - **Test MAE**: **6.3070** (vs. naïve baseline MAE = 11.1095, a **+43.23% MAE improvement**)
  - **Test RMSE**: **7.9104** (vs. baseline RMSE = 13.4357)
  - **Test Pearson $r$**: **0.8082**
  - **Test Spearman $\rho$**: **0.8179**
- **Canonical Specialist**: The **Core-5 Acoustic Ridge Regressor** is designated as the **canonical / recommended V2 Voice DDS Specialist**, translating acoustic signals into predicted DDS with positive, clinically consistent weights.

## 2. Voice Engine Lineage & Missing Voice Representation

### A. Architectural Lineage
The Voice Engine extracts acoustic and prosodic features from audio statements and interviews via Librosa, producing two classification probabilities alongside raw acoustic properties:

```text
Audio Recording (.wav)
      │
      ▼
┌────────────────────────────────────────────────────────┐
│  Acoustic Signal Processing (Librosa)                  │
│  - Pause Ratio, Speech Rate, RMS Energy                │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│  Acoustic ML Models (Joblib Classifiers)               │
│  - voice_distress_model                                │
│  - acoustic_indicator_model                           │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│  Standardized Voice Outputs in Dataset                 │
│  - Voice_Distress        (distress probability)        │
│  - Pause_Ratio           (speech pause fraction)       │
│  - Speech_Rate_Deviation (prosodic timing deviation)   │
│  - Energy_Deviation      (amplitude variation)         │
│  - Acoustic_Indicator    (composite trauma score)      │
└────────────────────────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────────────────────────┐
│  V2 Voice DDS Specialist Regression Layer              │
│  y = Intercept + ∑ (w_i * feature_i)                   │
└────────────────────────────────────────────────────────┘
      │
      ▼
Predicted Current-Timepoint DDS
```

### B. Missing Voice Representation Analysis

Across the 30,000 longitudinal observations in `MEDHA_Synthetic_1000x30_DDS_Regenerated.xlsx`:
- **Available Voice Observations (`Voice_Available == 1`)**: **10,995 rows (36.65%)**
- **Missing Voice Observations (`Voice_Available == 0`)**: **19,005 rows (63.35%)**

#### Critical Audit Finding on Missing Voice:
When `Voice_Available == 0`, all 5 primary acoustic features are strictly `NaN` (19,005 / 19,005 rows).
Converting missing voice samples into "0.0 distress" would introduce severe clinical distortion, falsely classifying non-recording victims as having zero emotional distress.

**Preserved Policy**:
1. Missing voice rows are represented as `NaN` (unobserved).
2. Primary training and evaluation are conducted on available voice observations (`Voice_Available == 1`).
3. In prediction outputs, `Voice_Available` is preserved and clean predictions are set to `NaN` when unobserved, allowing the downstream Fusion Engine to mask or ablate the voice modality dynamically.

## 4. Strict Boundary & Leakage Enforcement

The Voice Specialist is subject to hard-failing validation (`validate_voice_specialist_features` in `engine/v2/v2_feature_policy.py`):

1. **Target Lags Banned**: `Previous_DDS`, `Rolling_DDS_Mean`, `Rolling_DDS_SD`, `DDS_Slope`, `Recent_Change_Rate`, `Delta_DDS`, `Baseline_DDS` are rejected.
2. **Targets Banned**: `DDS`, `Future_Escalation_Label` are rejected.
3. **Structured Modality Banned**: `Mood`, `Stress`, `Sleep`, `Safety`, `Case_Type`, `Engagement_Score`, etc., are rejected.
4. **Text Modality Banned**: `Text_Distress`, `Fear`, `Negative_Affect`, `Urgency`, `Threat_Context`, etc., are rejected.
5. **Metadata Banned**: `Victim_ID`, `Case_ID`, `Timepoint`, `Date_Time`, `Intervention`, `Follow_Up` are rejected.
6. **Zero Duplicates**: Any duplicated feature causes immediate termination.

## 6. Model Architecture & Training Details

Three models were evaluated:

### Model 1: Core 5 Acoustic Ridge Regressor (Canonical / Recommended Voice Specialist)
- **Status**: **Canonical Specialist** for MEDHA V2 Voice DDS inference.
- **Inputs**: 5 Core acoustic features (`Voice_Distress`, `Pause_Ratio`, `Speech_Rate_Deviation`, `Energy_Deviation`, `Acoustic_Indicator`).
- **Algorithm**: Regularized Linear Ridge Regression ($\alpha = 1.0$).
- **Advantages**: Fully interpretable, strictly positive weights; exact correspondence with acoustic features.

### Model 2: Core 5 Acoustic XGBoost Regressor
- **Status**: Nonlinear baseline on Core 5 features.
- **Hyperparameters**: `n_estimators=100`, `max_depth=4`, `learning_rate=0.05`, `subsample=0.8`, `colsample_bytree=0.8`, `random_state=42`.

### Model 3: Extended 9-Feature XGBoost Regressor (Diagnostic / Ablation Artifact)
- **Status**: **Diagnostic / Ablation Artifact** to evaluate whether longitudinal baseline/trend traits add incremental value beyond the 5 core acoustic signals.
